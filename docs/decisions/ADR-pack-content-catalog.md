# ADR：按 Minecraft 版本建立包内内容目录

- 日期：2026-09-07
- 状态：已实施

## 问题

`mod_content` 保存 JAR 中的原始文件，适合追溯，但不适合稳定完成物品 ID 与名称映射、标签展开、反向标签查询、方块关联和配方材料查询。仅从当前选中模组读取语言和标签还会漏掉原版资源及其他已安装模组。

## 决策

保留 `mod_content` 作为模组原始解析层，新增按 `pack_id` 隔离的派生内容目录。目录包含：

- 物品、方块以及物品与方块的对应关系；
- 按 locale 保存的物品名和方块名，读取时按所选语言、`en_us`、资源 ID 回退；
- 分 registry 保存的物品标签和方块标签；
- 标签的原始定义、直接成员/嵌套标签边以及递归展开后的成员；
- 配方原始 JSON，以及按输入/输出、槽位、候选项保存的物品或物品标签引用；
- 由版本模型和纹理生成的 PNG 图标；
- 来源版本、构建状态、警告和 source/built revision。

名称只用于显示，不参与物品等价判断。具体物品配方精确匹配 ID；只有标签材料才展开候选成员。同名不同 ID 始终保留为不同物品。

原版初始化读取所选版本经 SHA-1 校验的 Minecraft 客户端/数据资源包，范围为物品、方块、配方、物品与方块标签、语言、模型和纹理；地形、结构、战利品和进度不进入目录。`zh_cn` 通过该版本的 Mojang asset index 获取并校验，`en_us` 来自版本包。资源包缓存到磁盘，结构化目录按整合包存储。

创建整合包或修改 Minecraft 版本后提交 `catalog_init` 持久化任务。模组解析成功后提交同类重建任务。构建在事务外解析和渲染，最终通过期望 `source_revision` 原子替换；期间发生来源变化则拒绝提交，旧目录保持完整。

标签的 `replace`、`remove`、可选项和加载条件保留在定义/直接边中。无法静态判断的加载条件标记为部分解析，不伪造成确定成员。展示代表图标不写回标签成员事实。

## 影响

数据库迁移为 0013（目录表）和 0014（`catalog_init` 任务类型）。新增目录状态、读取、重建、单项关系和图标接口。完整 1.21.1 版本包验收得到 1,754 个物品、1,062 个方块、1,290 个配方和 331 个标签。
