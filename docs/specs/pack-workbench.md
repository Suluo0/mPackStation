# 整合包工作台 `/packs/:id`

## 页面目的

用户在一个包的作用域内搜索模组、查看已选清单、锁定依赖，并处理待解决冲突。

## 布局

- 顶部包上下文栏：封面、包名、MC 版本、加载器、包版本、保存状态、主操作“打包”。
- 左侧窄导航：概览、模组、依赖与冲突、内容编辑、任务书、打包发布。
- 主区三段：顶部搜索和筛选；中部搜索结果或已选模组；右侧固定“包健康”摘要。
- 底部状态条：已选模组、已安装模组、待解决冲突、后台索引进度。

## 核心组件

`PackContextBar`、`ModSearchToolbar`、`ModResultRow`、`SelectedModRow`、`DependencyNotice`、`ConflictDrawer`、`PackHealthRail`。

## 状态

初始空包、搜索中、已加入待索引、依赖待确认、冲突待处理、全部解决、接口失败。

## 视觉重点

这是信息密度最高的页面。减少大卡片，用分组、细描边和状态色组织内容；主操作保持 ember 橙，健康信号使用绿/红/青。
