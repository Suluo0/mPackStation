# 页面设计总览

所有页面共享 `docs/design/taster-visual-language.md`：暖纸底、矿物黑、ember 橙品牌色、青色信息色、14px 卡片圆角、紧凑但可扫读的工作台密度。

本组页面按“包是唯一工作对象”组织。模组搜索不作为全局页面，而是整合包工作台的主区域。

页面顺序：

1. `pack-workbench.md`：选模组、看依赖、处理冲突的主战场
2. `content-editor.md`：配方、结构、矿脉的统一内容编辑器
3. `quest-editor.md`：任务书节点与奖励编排
4. `publish.md`：校验、打包、导出和平台发布
5. `settings.md`：平台连接、存储、缓存和默认偏好

每页先以 mock 数据做静态视觉验收，再接真实接口。
