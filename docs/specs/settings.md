# 设置 `/settings`

## 页面目的

集中配置平台连接、文件位置、缓存策略和默认创建偏好。

## 布局

- 左侧设置分组：平台连接、存储与缓存、默认包配置、界面。
- 主区每组使用连续表单区块，不使用大量独立卡片。
- CurseForge / Modrinth 连接卡显示 Key 配置状态、连通测试和最后检查时间。
- 存储区显示目录、缓存占用、剩余空间和清理入口。
- 底部固定保存栏，仅在有未保存修改时出现。

## 核心组件

`SettingsRail`、`ProviderConnectionCard`、`StorageMeter`、`DefaultPackForm`、`StickySaveBar`。

## 状态

未配置、已连接、连接失败、保存中、保存成功、危险操作确认。

## 视觉重点

最克制的一页。以表单节奏和状态反馈为主，不使用 hero、插画或大面积装饰。
