# 任务书 `/packs/:id/quests`

## 页面目的

把整合包的目标、章节、解锁条件和奖励编排成可玩的任务路线。

## 布局

- 顶部包上下文栏，显示任务书保存状态和预览按钮。
- 左侧章节列表：章节封面色、完成度、任务数、拖拽排序。
- 中央节点画布：任务节点、依赖连线、分支和章节分隔。
- 右侧节点属性面板：标题、描述、图标、前置条件、奖励、关联模组。

## 核心组件

`ChapterRail`、`QuestCanvas`、`QuestNode`、`QuestInspector`、`RewardPicker`、`QuestPreview`。

## 状态

空任务书、章节编辑、节点选中、连线校验失败、奖励缺失、预览模式。

## 视觉重点

画布底色为深墨绿，节点像纸牌一样分层；章节颜色只做分组，不承担成功/失败语义。连线和选中态使用 ember 橙。
