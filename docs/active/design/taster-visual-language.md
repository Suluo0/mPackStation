# mPackStation · Taster 视觉语言

## Design read

这是一个面向 Minecraft 整合包作者的桌面工作台，不是营销落地页。视觉采用 **tactile workbench**：矿物中性色、纸张底、单一 ember 橙品牌色，信息密度偏高但保留清晰的工作节奏。

设计拨盘：`DESIGN_VARIANCE 6 / MOTION_INTENSITY 3 / VISUAL_DENSITY 7`。

## 语言规则

- **底色**：暖纸色与极轻网格纹理，减少大片空白带来的“模板后台”感。
- **品牌色**：ember 橙只用于主行动、选中态和品牌标识；不再使用 AI 紫渐变作为默认视觉。
- **语义色**：绿只表示已解决，红只表示失败/待处理，蓝青只表示信息或平台连接。普通入口按钮不使用绿色。
- **材质**：卡片使用近白纸张底、细暖灰描边和低强度阴影；大多数层次由间距和排版表达。
- **形状**：卡片 14px、控件 9px、状态胶囊保留全圆角，形成稳定的三级形状系统。
- **排版**：标题使用紧字距和更强字重；数据使用等宽数字；辅助文字降低对比度但不降低可读性。
- **结构**：侧栏 184px、顶栏 60px、内容区紧凑；包工作台上下文内才出现模组搜索入口。
- **动效**：只保留 hover 上浮、按压反馈和进度过渡，时长约 140ms。

## 禁止回退

- 不恢复全局“模组搜索”导航。
- 不把绿色用于普通 CTA。
- 不用纯色渐变块代替包封面；mock 封面至少要有天空、地形和光源层次。
- 不通过增大圆角、阴影和留白来制造“高级感”。
