### M2 加载器安装实现
- **loader/mod.rs**: 统一 `LoaderInstaller` 接口，`LoaderType` 枚举（Fabric/Quilt/Forge/NeoForge）
- **loader/fabric.rs**: 从 Fabric Meta API 获取 loader 版本列表 + profile JSON，写入后用自研下载层下载
- **loader/quilt.rs**: 同 Fabric，从 Quilt Meta API 获取
- **loader/forge.rs**: 从 Maven metadata 获取版本列表，下载 installer.jar，用 Java 执行 `--installClient`，然后补全下载
- **loader/neoforge.rs**: 同 Forge，从 NeoForged Maven 获取

### 设计要点
- Fabric/Quilt 是 profile 型：meta API 返回完整 VersionJson，写入即可
- Forge/NeoForge 是 installer 型：需要下载 installer.jar 并用 Java 执行，installer 会生成版本 JSON 和库文件
- 所有加载器安装后都调用自研下载层做校验补全（支持 BMCLAPI 镜像）
- 支持指定 loader 版本或自动选最新稳定版
