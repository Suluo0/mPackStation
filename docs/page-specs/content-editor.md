# 内容编辑 `/packs/:id/content`

## 页面目的

不打开外部编辑器，直接配置配方、结构生成和矿脉。

## 布局

- 顶部包上下文栏和“保存草稿 / 应用到包”操作。
- 左侧内容类型切换：配方、结构、矿脉；每类显示条目数和待发布数。
- 中央编辑画布：配方使用输入/输出槽位与连接线，结构和矿脉使用参数表单加预览区域。
- 右侧检查栏：校验结果、受影响模组、冲突提示和撤销历史。

## 核心组件

`ContentTypeRail`、`RecipeCanvas`、`StructurePreview`、`OreRuleForm`、`ValidationRail`、`DraftStatus`。

## 状态

无内容、编辑中、校验通过、校验警告、保存中、保存失败。

## 视觉重点

编辑器采用深色矿物画布，外围仍是暖纸工作台；输入输出槽位使用 ember 描边，错误才用红色，不用装饰性渐变。
