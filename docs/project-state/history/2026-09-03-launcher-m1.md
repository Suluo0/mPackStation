## 关键决策

1. **下载层必须自研**: mc-launcher-core 高层 API 不支持镜像源（Launcher 字段全私有），国内直连 Mojang 不可靠
2. **系统代理自动检测**: reqwest 不读取 Windows 系统代理设置，需手动从注册表读取并验证可用性
3. **BMCLAPI 限速**: 32 并发会被 BMCLAPI 拒绝，降至 8 并发 + 5 次重试后稳定
4. **输出协议**: 只有 phase + result 两种事件，不做进度条；tracing 日志走 stderr，protocol 事件走 stdout
